# 🧮 Calculator — Scientific Calculator

A modern, responsive scientific calculator built using **HTML, CSS, and JavaScript**, featuring a black, yellow, and neon theme with a clean, square-button interface.

## ✨ Features

- ➕ Basic arithmetic operations
- 🔬 Scientific functions: `sin`, `cos`, `tan`, `log`, `ln`, and `√`
- 📐 Degree and radian modes
- 🔢 Constants: π and Euler's number (e)
- ⚡ Powers, factorials, percentages, and parentheses
- 🕘 Calculation history saved in local storage
- ⌨️ Keyboard support
- 📋 Copy results to clipboard
- 📱 Responsive user interface
- 🎨 Black, yellow, and neon color theme
- 🔒 Custom expression parser without using `eval()`

## 🛠️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Calculator logic and scientific operations
- **Local Storage** — Persistent calculation history
